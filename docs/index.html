                çevrilir; ayrı mikrofon kaydı varsa 1 ms RMS zarf korelasyonuyla sıfır kare kaymayla
                kameraya kilitlenir.

                ffmpeg-skill

                > 0.20 sn boşluklar kesilir.

          02 · DAHİLİ SKİLL · real-broll-capture
          

            Sahte site maketleri yok:
            3 katmanlı gerçek B-roll
          

          

            Depoyla birlikte gelen skills/real-broll-capture/ skill'i, konuşmada geçen
            kaynakları ve siteleri headless Chrome ile canlı yakalayıp doğrudan HyperFrames'e hazır
            bt709 30 fps CFR dosyalara çevirir.
          


          

            

              KATMAN 01 · --mode source
              
Gerçek Kaynak Yakalama

              

                Resmi bloglar, araştırma makaleleri ve dokümanlar 540×960 @2x
                (1080×1920 Retina PNG) olarak çerez banner'ları otomatik gizlenip
                yakalanır ve SOURCES.md defterine kaydedilir.
              

            


            

              KATMAN 02 · --mode record
              
Canlı Site Ekran Kaydı

              

                Bahsedilen web sitesi veya GitHub reposu akıcı kübik kaydırma, gerçek CSS
                :hover tepkileri ve vektör macOS imleciyle kare kare kaydedilip
                -g 15 -bf 0 hızlı-seek MP4'e çevrilir.
              

            


            

              KATMAN 03 · AI / KOD SAHNE
              
Sıfırdan Üretilen Sahneler

              

                Gerçek görüntüsü olmayan soyut veya fütüristik kavramlar için tam ekran 9:16
                sinematik AI görseli / kodlu Canvas 2D sahnesi üretilir ve ekranda şeffaf biçimde
                etiketlenir.
              

            

          


          

            

              ÖRNEK KOMUT · skills/real-broll-capture/scripts/capture_site.mjs
              
            

            

              
# 1) Gerçek birincil makaleyi 2x Retina PNG yakala
$ node skills/real-broll-capture/scripts/capture_site.mjs --mode source --url "https://blog.google/technology/google-deepmind/" --out assets/sources/real-source.png --theme light

# 2) Canlı siteyi kaydırma + imleçle 30fps CFR MP4 olarak kaydet
$ node skills/real-broll-capture/scripts/capture_site.mjs --mode record --url "https://github.com/heygen-com/hyperframes" --out assets/sources/screen-record.mp4 --duration 2.0 --scroll-distance 600 --theme dark
